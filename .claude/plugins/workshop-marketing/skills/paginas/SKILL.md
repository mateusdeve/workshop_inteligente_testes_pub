# Páginas — Base de Conhecimento

## Estrutura 8D (Página de Vendas VTSD)

1. **Primeira Dobra** — Premissa (headline) + subheadline + 3 bullets (Urgência Oculta + Decorado) + vídeo
2. **Paliativo** — O que já tentaram e por que falhou
3. **Método** — Apresentação da Furadeira (macroetapas + microetapas)
4. **Entregáveis** — Lista completa com metáforas de valor
5. **Bônus** — 3 bônus estratégicos com valor individual
6. **Prova Social** — Depoimentos com foto e resultado específico
7. **Garantia** — Tipo + prazo + selo visual
8. **Oferta Final** — Ancoragem de valor + preço + parcelamento + CTA

## Padrão HTML

- Arquivo único (CSS inline, Google Fonts, zero dependências)
- Mobile-first, 100% responsivo
- Paleta: máx 3 cores + neutros
- Animações CSS sutis
- Botões grandes com hover
- Placeholders de imagem
