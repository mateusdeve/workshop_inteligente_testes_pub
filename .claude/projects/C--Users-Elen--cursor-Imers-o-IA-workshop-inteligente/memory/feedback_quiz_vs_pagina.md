Nunca recomendar quiz automaticamente para low ticket. Aplicar o framework de 6 critérios antes de qualquer recomendação.

**Why:** O assistente recomendou quiz + página como funil padrão sem analisar os critérios. O correto é aplicar o framework e deixar os dados do produto decidirem. Produtos práticos/ferramenta com público consciente do problema tendem a pedir PÁGINA, não quiz.

**How to apply:** Sempre que o aluno perguntar "faço quiz ou página?", aplicar a tabela de 6 critérios (tipo de produto, nível de consciência, complexidade, habilidade técnica do mentorando, faixa de preço, tipo de público). 2+ critérios para um lado = seguir. Empate = quiz. Nunca sugerir "os dois" como padrão.
