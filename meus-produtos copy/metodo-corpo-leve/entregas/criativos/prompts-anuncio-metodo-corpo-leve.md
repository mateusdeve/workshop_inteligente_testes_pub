## Como usar no Gemini

1. Acesse o Gemini com geração de imagens ativada
2. Cole o prompt completo de cada variação
3. Para ajustar cores, adicione ao final: `Color palette: white, beige, sage green`
4. Teste pelo menos 3 variações para comparar qual performa melhor
