# Meu Negócio

Esta pasta armazena as informações do seu produto/negócio.

Use o comando `/meu-produto` no chat do Claude para preencher seu perfil automaticamente.

O arquivo `perfil.md` será criado aqui com todas as informações que o assistente precisa para personalizar seus materiais de marketing.

Com `/idconsumidor`, o assistente gera `idconsumidor.md` com a identidade do consumidor (cliente ideal): demografia, paliativos, objeções e tom de voz.
